01 / CONSERVATIVE FACE FLUX

A linearization that recognizes finite jumps.

At each reconstructed left/right face pair, Roe replaces the nonlinear homogeneous flux by a matrix whose action on the conservative jump equals the physical flux jump. It differs from simply evaluating a physical Jacobian at an averaged pressure and enthalpy. Geometry and source terms remain in the existing finite-volume residual.

F^=12(FL+FR)−12∑kKφk(λk)Pk(UR−UL),A~ΔU=ΔF

The physical model supplies conservative spectral projectors P, wave speeds λ, entropy widths and a validity flag. The shared numerics/roe.py only contracts these arrays; it assumes neither Euler variables nor an EOS, and the number of wave groups can differ from the number of variables. The operator applies face geometry and area exactly once. Nozzle/annular face_data can reuse endpoint EOS data through a fused Roe callback.

02 / GENERAL EOS FROM THE EXISTING PROPERTY INTERFACE

Pressure and enthalpy remain the numerical inputs.

Nozzle unknowns are (p,u,h); annular unknowns are (p,u,ell,h). Every thermodynamic property evaluation in the production Roe path uses fluid.get_state(HmassP_INPUTS, h, p). The construction consumes density ρ, sound speed a and Grüneisen coefficient G. Internal energy follows from e = h − p/ρ; it requires no density–energy EOS inversion.

dp=χdρ+κd(ρe),κ=G,χ=a2−Gh

This differential identity follows from a² = (∂p/∂ρ)s and G = (1/ρ)(∂p/∂e)ρ. A fixed model-reservoir reference defines eref = href − pref/ρref. The implementation constructs the matrix in centered energy I = ρ(e − eref), for which χc = a² − G(h − eref). This prevents an arbitrary enthalpy reference from contaminating the numerical averaging.

03 / CENTERED, SCALED SECANT PROJECTION

Thermodynamic slopes must also match the two-state pressure jump.

Write a square-root-density average as ⟨q⟩ = (√ρL qL + √ρR qR)/(√ρL + √ρR). Meridional/transverse velocities and centered total enthalpy use this average. Provisional thermodynamic slopes are χc,0 = ⟨a² − G(h − eref)⟩ and κ0 = ⟨G⟩.

For a finite jump, the slopes are projected onto the pressure-secant constraint. The dimensions and energy zero are controlled with fixed positive reference scales:

x=Δρρref,y=ΔIρrefaref2,d=Δppref,g=ρrefχcpref,b=ρrefaref2κpref

The energy-density jump is evaluated without subtracting two large energies: ΔI = Δρ · [(hL + hR)/2 − eref] + [(ρL + ρR)/2 · Δh − Δp. Let r = d − g0x − b0y and s = x² + y². The implemented correction is

(g,b)=(g0,b0)+β(s)rs(x,y),β=t3(10−15t+6t2)

Here τ = ε1/3, t = clip[(s/τ² − 1)/3, 0, 1], and ε is machine precision. For s ≤ τ² the correction is zero with a safe inactive denominator; for s ≥ 4τ² it is the full orthogonal projection. The quintic transition is C². This avoids dividing property/subtraction noise by tiny jumps while retaining the physical differential limit and usable JAX derivatives. The raw convective absolute-value kink is intentionally retained.

The full projection enforces Δp = χcΔρ + κΔI up to rounding. The tiny-jump blend is not claimed to be an exact secant; every face must pass the explicit mixed audit |d − gx − by| ≤ 4096 ε (1 + |d| + |gx| + |by|). This audit accommodates the existing PH backend's state resolution and does not relax flow-solver stopping tolerances. The rule is an implemented centered projection, not a verbatim published Vinokur–Montagné formula.

04 / EULER WAVES AND ANNULAR GEOMETRY

One thermodynamic construction, three grouped eigenspaces.

With averaged velocities ũ, ṽ, kinetic energy K = (ũ² + ṽ²)/2 and centered total enthalpy H̃c = ⟨h − eref + (u² + v²)/2⟩, the Roe sound speed satisfies ã² = χc + κ(H̃c − K). The three wave groups have speeds ũ + ã, ũ − ã and ũ. The convective group contains entropy alone in the nozzle and entropy plus transverse shear in annular flow.

The centered conservative annular variables are Uc = (ρ, ρu, ρv, ρ[E − eref]). With C = χc + κK, the matrix assembled by the physical model is:

The nozzle matrix is obtained by setting v = 0 and deleting its transverse row and column. Define B = Ãc − ũI. Polynomial projectors avoid choosing individual basis vectors for a repeated eigenvalue:

The source returns these projectors to the physical energy reference by similarity with T = I + eref eEeρT. For annular faces, both sides first use the same fixed face radius: v = ell/rf. The local transverse-momentum flux is then transformed to angular-momentum flux by D = diag(1,1,rf,1). The conservative jump is in that common unweighted local frame. Geometry remains stationary and sources are not hidden inside the Roe matrix.

05 / ENTROPY REGULARIZATION AND TRIAL VALIDITY

Acoustic smoothing, exact convective dissipation, strict rejection.

Acoustic eigenvalues use the Harten regularization below; the convective/contact/shear width is exactly zero, giving φ0 = |ũ|. For each acoustic sign, let σ± = (uR ± aR) − (uL ± aL) and b = delta_factor · ã. The actual width is δ± = b + [σ± + √(σ±² + b²)]/4.

φ(λ,δ)={λ2+δ22δif δ>0 and |λ|<δ|λ|otherwise

Admissible endpoint properties, a satisfied secant audit, positive finite ã², finite projectors and finite nonnegative widths are required. The implementation does not clip an invalid sound speed or silently switch to HLL. Safe inactive arithmetic prevents invalid divisions during JAX tracing, but it does not make an invalid face valid; the solver rejects the trial.

Explicit Euler and SSPRK3 use the interface bound maxk φk in addition to the existing cell/geometry/source restrictions. This matters because averaged annular transverse shear can make interface dissipation exceed cell acoustic speeds. Explicit boundary traces are solved segregated at each required stage; backward Euler can use either coupled or segregated traces. Boundary physics, nonlinear convergence rules, reconstruction and sources remain independent of the selected flux.

06 / INTERPRETING THIS IMPLEMENTATION

What is established, and what remains outside the claim.

The method recovers the physical differential limit and classical perfect-gas Roe construction, captures stationary contacts/shear through the convective projector, and satisfies the audited finite-jump relation. Tests and the independent actual-CO₂ audit check these claims, including reference-energy shifts and tiny-jump automatic differentiation. The Protocol & provenance page contains measured results, raw evidence and the retained failures/budget stops.

No global positivity guarantee or general nonlinear entropy theorem is asserted. A general-EOS interface still requires thermodynamically consistent density, sound speed and Grüneisen data on the selected smooth branch. Independently interpolated property tables, phase switching and the future two-fluid model require separate validation. JAXProp's existing host-fluid JVP bridge uses one-sided finite differences, so derivative accuracy is limited by that backend. Real-gas flow verification is less extensive than perfect-gas verification; no comparative speed ranking has yet been established.
