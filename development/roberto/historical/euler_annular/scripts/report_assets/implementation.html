Implemented contracts / reproducibility

Implementation & use

The public solver, geometry and fluid interfaces, shared infrastructure and commands needed to reproduce the study. This chapter describes the implemented prototype; completed planning documents are historical records.

Public solver interface

The installable package is nozzle_hyperbolic. Use 64-bit JAX. The physical model is quasi-one-dimensional and axisymmetric, with meridional flow, swirl and optional distributed wall shear/heat sources. Its zero-wall limit is inviscid and adiabatic. The full primitive state has shape (N+2, 4): inlet face trace, physical cells, outlet face trace. Variables are (p, v_m, ell, h), with v_theta=ell/r. Storage contains mass, meridional momentum, angular momentum and total energy; the two face traces have zero storage.

import jax
jax.config.update("jax_enable_x64", True)
import jaxprop as jxp
from nozzle_hyperbolic.geometry.annular import radial_channel
from nozzle_hyperbolic.models.euler_annular import make_annular_solver

fluid = jxp.FluidPerfectGas(name="Air")  # Verification backend.
mesh = radial_channel(r_in=0.10, r_out=0.20, b=0.005).mesh(100)
solver = make_annular_solver(
    fluid, mesh,
    inlet_data={"p0": 200000.0, "T0": 300.0, "alpha_in": 0.0},
    outlet_pressure=199000.0, reconstruction="muscl_van_leer",
    tau_w=0.0, q_w=0.0,
)
solution = solver.solve_steady(tolerance=1e-8, max_steps=3000)
fields = solver.fields(solution.state)

Named wall-source placeholders

The public shear_stress_wall(W, r, fluid, prescribed=...) and heat_flux_wall(W, r, fluid, prescribed=...) functions are exported from nozzle_hyperbolic.models.euler_annular and implemented in closures/wall.py. They currently broadcast the prescribed values, defaulting to zero. Current-state, radius and fluid arguments reserve the location for future constitutive laws; there is no configurable runtime callback interface.

Factory tau_w is a finite nonnegative shear magnitude in Pa. q_w is a finite signed heat flux in W/m², positive into the fluid. Each accepts a scalar or one value per physical cell. Inputs are fixed at factory construction; rebuild to change the profile. No viscosity/Reynolds-number/roughness correlation, heat-transfer coefficient or wall-temperature model is implied. The source acts on meridional momentum and angular momentum through drag and torque; only heat flux changes total energy. The theory discussion gives the equations and the defined zero-speed direction.

This example uses the production driver's defaults. The measured verification campaign explicitly uses the separate fixed-growth controller described in Controller findings: CFL 0.2, growth 1.2, shrink 0.5 and a cap of eight strict Newton corrections. Passing growth 1.2 to the production work-threshold controller is a different policy.

Public operators include residual, steady_residual, spatial_residual, boundary_residual, storage, face_flux, source, jacobian, dense_jacobian, compute_dt and metrics. advance(initial_state, final_time) performs backward-Euler physical-time integration. Its initial traces must already satisfy the algebraic boundary equations. Steady pseudo-time settings do not determine physical-time accuracy.

YAML cases and monitored single-case runs

The verification inputs are defined by a shared cases/common.yaml template and the physical overrides in cases/verification.yaml. They contain geometry, fluid, boundary data, mesh, reconstruction, prescribed wall sources, residual policy, controller and named engineering monitors. The Python reference builder interprets these inputs; it no longer selects physical data with case-name branches.

poetry run python -m development.roberto.historical.euler_annular.scripts.run_case --list-cases
poetry run python -u -m development.roberto.historical.euler_annular.scripts.run_case --config development/roberto/historical/euler_annular/cases/verification.yaml --case radial_outflow --cells 100 --reconstruction constant

The runner prints initial and accepted states in at most 100 characters per line: iteration, CFL, timestep, Newton corrections, overall residual R, equation residuals R1–R4, and separate boundary/global checks. R is the maximum active initial-relative equation residual. Engineering quantities remain in the saved history and stopping checks, outside the printed table. It writes resolved configuration, source hashes, initial/final states and complete accepted/rejected histories. Every active equation must reduce by nine orders and pass its absolute safeguard. A cap, retry failure or unattained relative target remains a failure.

For example, a monitor entry can be configured as:

monitors:
  - name: Cp_mean
    quantity: pressure_coefficient
    reduction: length_mean
    convergence: true
    window: 20
    absolute_tolerance: 1.0e-8
    relative_tolerance: 1.0e-6
    reference: 1.0
  - name: mdot_out
    quantity: mass_flow
    reduction: outlet
    convergence: true
    window: 20
    absolute_tolerance: 1.0e-10
    relative_tolerance: 1.0e-6
    reference: 1.0

Each enabled monitor requires its peak-to-peak variation over a complete window to be at most the absolute tolerance plus relative tolerance times the fixed reference. Setting convergence: false records the quantity without making stationarity a stopping requirement. Residual reducers, scalar-window tracking and table printing live in reusable solvers/ modules; the annular adapter owns Cp and numerical mass-flux evaluation. EulerNozzle remains on its existing behavior.

General-EOS fluid contract

Trial states use fluid.get_state(jxp.HmassP_INPUTS, h, p). Required properties are density rho, sound speed a, dimensionless Grüneisen G, temperature T, entropy s and returned p,h. Native JAXProp/custom JAX objects preserve their own implementation; raw host Fluid and FluidMix objects use JAXProp's existing callback/custom-JVP bridge while retaining the configured host object. Host derivatives have the accuracy and concurrency limits of that bridge.

The numerical FVM, boundary equations, initialization and scaling use no perfect-gas closure or heat-capacity ratio. The perfect-gas formulas in the analytical-reference appendix are verification oracles. An HP-only backend may supply inlet h0,s0,p0 instead of p0,T0. Setup checks finite properties, positive density/sound speed/temperature, domain bounds, returned coordinate consistency and the Gibbs response. Enthalpy/internal-energy reference shifts are allowed. Invalid states are rejected, not clipped.

Conservative-to-primitive recovery is a setup/postprocessing helper. A valid direct density/internal-energy state is used when available; unsupported host pairs fall back to a strict HP bracket with physical bounds or a supplied pressure guess. That host root recovery is outside the primitive-variable residual and boundary closure. The present perfect-gas flow campaign and nonideal interface fixtures do not constitute real-fluid application validation.

NURBS geometry contract

make_annular_geometry(midline, height) accepts a NURBSpy midline (x,r) and an independent scalar normal-height spline parameterized by normalized arclength. radial_channel, conical_channel and circular_arc_channel are particular cases through the same metric builder. Nonuniform physical faces are supplied using geometry.mesh(m_faces=...).

The recorded stack uses NURBSpy 1.6.0 NumPy, JAX/JAXlib 0.6.2 and JAXProp 0.5.8, with Python 3.12–3.13. NURBSpy 1.6's optional JAX extra requires JAX 0.12, outside that JAXProp release's supported stack. Geometry is fixed host preprocessing; fluid-state/residual differentiation remains in JAX. Geometry-shape AD is deferred.

Arclength integration is split at knot spans. The adapter checks NURBSpy's ten-point length rule against a 32-point derivative rule, with adaptive quadrature when needed, and uses a bracketed inverse. It implements no second spline evaluator. Verified affine degree-one, equal-weight curves use the exact inverse; rational/non-affine parameterizations retain controlled inversion. Derivatives apply the parameter-to-arclength chain rule. Volumes are integrated rather than replaced by midpoint area times width.

The builder checks positive represented width/radius and wall radii, nonzero midline speed and the local regular-offset condition. Individual spline control ordinates need not themselves be positive if the represented geometry remains valid. General offsets are sampled from the midline and normal height; they are not assumed to be exact NURBS curves. Global wall self-intersection detection is not implemented. Corners/discontinuous width require separate modeling. Conical width follows the specified cant and wall semi-divergence angles; other selected fixtures have constant normal width.

Coupled boundaries and shared machinery

There are exactly four residual rows per boundary and four balance rows per physical cell. Independent exterior traces are at physical faces, not arbitrary ghost-center radii. Current traces enter numerical face fluxes and Jacobians. Old boundary slots and timestep size do not enter boundary storage. HP properties are evaluated directly; no nonlinear boundary root, fixed-count inversion or post-Newton ghost overwrite is nested inside the residual.

Subsonic inlet constraints impose total enthalpy, entropy and a fixed inlet angle, plus outgoing acoustic compatibility. Subsonic outlet constraints impose pressure plus outgoing acoustic, entropy and angular-momentum information. Supersonic inlet/outlet modes prescribe/extrapolate all four primitives. The two-cell outgoing reference uses actual nonuniform distances and current EOS impedance. It is a local characteristic projection, not an exact nonlinear invariant or proven nonreflecting boundary. Fixed inlet angle is retained in backpressure families; inlet angular momentum can change with the inlet state.

Modes are explicit factory choices, audited using signed meridional Mach numbers. Reverse flow and automatic boundary-mode switching are unsupported. An outlet prescribed as supersonic does not impose an ambient backpressure. Sonic limits and a physical-time regime change require explicit interpretation or rebuilding the boundary block.
