Metric definitions and original acceptance criteria

Spatial RMS: RMS of the original flux-difference-minus-source rows scaled by Vᵢ qref aref/L. Boundary maximum: the separate maximum of all eight scaled algebraic constraints. Conservation: (Fout − Fin − ΣSᵢ)/(Ainarefqref). Each root target is 10⁻⁸.

qref = (ρref, ρrefaref, ρrefrinaref, ρrefaref²). Transported-flux spreads use separately documented nonzero normalizations; they are not the same metric as the fixed-scale integrated balance.

Smooth finest-grid targets are max |ΔCp| < 10⁻³ and all four conservative L₁ errors < 10⁻³. The shock target is location error ≤ 2 cells. The sonic-exit discrepancy and local shock overshoot are retained, with no relaxed target or hidden reference seed.
