# Completed planning records

These files preserve the answered design questionnaire, implementation plan and
original planning snapshot. They describe the decisions and proposals at their
recorded checkpoint; they are not a second specification of the current solver.

Use [the standalone report](../REPORT.html) for current results, equations,
implementation contracts, controller findings, reproducibility and limitations.
The unselected internal-transonic geometry is explicitly identified there.
Mathematical/technical notes already consolidated into that report were removed
instead of copied into this archive. Links to those notes now target the report;
other historical source paths reflect the planning checkout.
