04 / MODEL, NUMERICS AND PROVENANCE

What this comparison establishes

The report carries its own data, plotting library and downloadable evidence.

01

Shared physical problem

Steady inviscid, adiabatic quasi-one-dimensional Euler flow of CO₂. All three methods use the same case-specific area law and reservoir. Adapted cases use outgoing supersonic extrapolation: the reference exit pressure is a design value, not an imposed FVM pressure. Shocked cases impose the prescribed backpressure.

ṁ = ρuA  ·  h₀ = h + u²/2
02

Real-gas thermodynamics

JAXProp equilibrium bicubic tables, 100 × 100 in enthalpy and logarithmic pressure. No ideal-gas replacement. The two-phase closure assumes homogeneous phase velocity and instantaneous mechanical, thermal and phase equilibrium.

ρ = ρbicubic(p,h)
03

Independent continuous reference

The established reference integrates dh/dp = 1/ρ, locates the choked mass flux, solves the Rankine–Hugoniot conditions, and iterates shock position to match backpressure. It contains ODE/root tolerances and tabulation effects; it is not an FVM solution.

[ρu] = [p + ρu²] = [h + u²/2] = 0
04

Acoustic consistency matters

Density, entropy and sound speed are independently interpolated. The selected matched reference’s consistency diagnostics appear here after loading.

a²Euler = [ρp + ρh/ρ]⁻¹

How errors should be interpreted

Normalized field errors use the saved reference comparison and declared scales. A shock creates a position-dependent integral error and lowers global convergence order; smooth-region and shock-location evidence should be read separately. Numerical convergence does not imply thermodynamic-table convergence. The Lettieri-type equilibrium case does not reproduce delayed nucleation or the experimental Wilson line.

Independent verification

Every mesh stage passes native convergence and an independent reduction of the original spatial residual, boundary equations and global conservation balance. Analytic errors assess discretization accuracy separately from convergence to the numerical steady root.

Cold state and grid transfer

The 50-cell stage uses the declared cold initialization. Finer grids receive the preceding successful mesh state through the production grid-sequence driver. The analytic solution is assessment data, not an initial field or a prescribed shock location.

General-EOS Roe flux

Roe uses density-weighted averages and a centered pressure-secant projection with a smooth small-jump limit. Its validity audit includes the declared regularization remainder. Positive endpoint density and sound speed, positive Roe acoustic speed squared and finite projectors are required. The raw secant defect and regularization diagnostics are available in the result audits.
