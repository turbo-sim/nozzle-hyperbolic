ALGORITHM & SETTINGS
Start coarse, then correct the fine grid
Both strategies build a numerical starting state on coarse grids. Their subsequent work differs.

  
01 / BASELINE
Grid sequencing
Converge the original problem on each grid once, moving from coarse to fine. A successful numerical state and accepted CFL initialize the next level. After moving upward, this strategy does not revisit coarse grids.
50 → 100 → 200 → 400
02 / INITIALIZED FAS
FAS with coarse-to-fine initialization
Converge the original coarsest problem, prolong a conservative state, and apply a recorded number of V-cycles as grids are added. Then converge the original finest-grid problem with further correction cycles. All initialization, recovery and coarse work is timed.
Coarse solve → nested initialization → fine-grid V-cycles

  
One implicit V-cycle
Take implicit smoothing steps on the current grid, restrict its state and signed integrated defect, approximately solve a forced coarse problem, then prolong the coarse correction and post-smooth. The same operation recurses down the hierarchy. A cycle can contain several implicit steps, Newton corrections, recoveries and rejected trials; its cost is not fixed.
400 → 200 → 100 → 50 → 100 → 200 → 400
The exact selected settings are retained in the campaign configuration and per-method diagnostics.

  
Why the coarse forcing matters
Write the integrated steady transport equations as $F_h(q_h)=f_h$, with $f_h=0$ on the finest grid. The current fine-grid defect is $d_h=f_h-F_h(q_h)$. Restrict transported densities using cell-volume weights, and sum integrated defects over each coarse cell.
$$q_H^0=I_h^Hq_h,\qquad f_H=F_H(q_H^0)+\mathcal R_h^H\bigl(f_h-F_h(q_h)\bigr).$$
The coarse solver approximately solves $F_H(q_H)=f_H$. Its additive correction is
$$q_h\leftarrow q_h+\theta P_H^h(q_H-q_H^0),\qquad 0<\theta\le1.$$
If the fine state already solves the original equations, its coarse initial state solves the forced problem and the correction is zero. Solving an unforced coarse problem at every visit does not have this fixed-point property.

  
Conservative transfers and algebraic traces
State restriction acts on transported densities, while residual restriction acts on signed integrated balances. They are different operations:
$$(I_h^Hq_h)_J=\frac{\sum_{i\in\mathcal C(J)}V_{h,i}q_{h,i}}{V_{H,J}},\qquad(\mathcal R_h^Hd_h)_J=\sum_{i\in\mathcal C(J)}d_{h,i}.$$
Endpoint states have zero storage and are not volume-averaged. Recover cell states from corrected contents, then solve each level's original boundary equations. Cell constraints and boundary rows receive no FAS forcing.
Why a speedup is uncertain
The existing implicit method already uses a global direct block-banded solve, with approximately linear work in cell count for a fixed stencil. Multigrid has to save enough nonlinear work to pay for coarse solves, transfers, recovery and dispatch. A successful cycle is not automatically a faster solver.
Every grid shape still specializes JAX kernels. A dynamic forcing array and stable level bindings permit reuse; they do not eliminate first-use compilation. Observed backend event durations include compilation or cache loading and are not pure compiler CPU time.

  
Separate active-grid and coarse-correction CFL
The current original problem can benefit from a large pseudo-time step once a good state is available. Its recursively forced coarse problems are auxiliary corrections and can behave differently. An optional coarse CFL cap applies only to those forced descendants; it does not cap the active unforced coarse solve used during initialization. Every rejected attempt and smaller retry is retained.
The main comparison includes each strategy's selected controller. A separate matched-controller run can distinguish an improvement from aggressive CFL settings from an improvement attributable to the multigrid cycle.
Better prolongation and an earlier finish
Optional linear initialization reconstructs transported densities while preserving each parent's integrated contents. Storage and physical boundary equations recover the new state through the model callbacks. Inadmissible slope trials are damped, with a recorded constant-prolongation fallback if needed. Analytical reference profiles never supply the initial state.
An optional fine-grid check after pre-smoothing ends a cycle immediately when all original finest-grid convergence checks pass, avoiding further coarse correction and post-smoothing after the target has already been reached. Its monitoring cost is included.

  
What can make initialized FAS faster?
The useful settings balance the quality of the starting state against the work spent producing it. Fewer intermediate cycles, fewer coarse steps, asymmetric pre/post smoothing, cheaper coarse reconstruction and a more effective CFL controller can reduce cost. They can also weaken a correction or increase rejected work. The selected campaign records the exact choices and tests the original finest-grid residual, physical branch and analytical accuracy independently.
For this small one-dimensional problem, the native block-banded global Newton solve is already inexpensive. A cycle must reduce fine-grid work enough to pay for repeated coarse solves, conservative transfers and storage/boundary recovery. The comparison therefore uses complete solve time rather than cycle count alone.

  
Validation scope
The campaign covers one Euler nozzle model with four operating points and two spatial reconstructions. The cycle and transfer interfaces are generic, but this campaign does not validate annular or two-fluid applications. Coarse forced states are auxiliary approximations; physical convergence and analytical accuracy are established on the original finest-grid problem.

Timing boundary
Each successful configuration receives one excluded complete solve and ten measured complete solves. Warm totals charge all grid levels, transfers, recovery, boundary completion, monitoring and rejected work. Numerical state and controller histories reset for every repetition.
Compilation observations from an excluded first solve are distinct from steady-state timing. Unless an isolated cache experiment is explicitly recorded, a first-solve duration is not an independent cold-start compilation benchmark.
Acceptance and failed work
Original spatial residuals, boundary defects, constraints, global balances, admissibility and physical branch checks must pass independently of inner Newton success. Analytical errors and same-discrete-root comparisons are separate gates.
A failed excluded solve remains visible with its reason and diagnostics; no timing samples are invented. Cap-limited coarse work and rejected steps/corrections contribute to the recorded effort. A plotted failed profile represents the state actually reached.
