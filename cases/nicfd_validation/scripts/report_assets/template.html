Comparison definition

The published interior profile is linearly interpolated to each new cell center, with bounded interpolation at the first/last samples. RMSE is the unweighted RMS of these point-profile differences. This is not a comparison of exact cell averages or a proof of grid independence. Hollow markers identify unsuccessful or unaudited cases; their errors describe unfinished states.

03 / ORIGINAL SPATIAL EQUATIONS

Convergence on each selected mesh

The archive has no iteration histories. These plots show the new solver, including rejected timesteps.

Every curve is an actual retained trajectory.
Convergence has several gates.

Every transported equation must meet relative 10⁻⁶ or absolute 10⁻⁹. Cell EOS constraints, endpoint equations and global/invariant defects have independent 10⁻⁹ limits. A case also has to pass its intended-regime audit. The Newton cap is 20, with update tolerance 10⁻¹⁰ and residual tolerance 10⁻¹². A small timestep or a small correction alone is insufficient.

04 / MODEL, SETTINGS AND PROVENANCE

What is held fixed

The file contains the plotting library, complete profiles, histories, settings and offered downloads.

01

One physical problem

Nitrogen gas and liquid water in the Elliot nozzle, length 0.31 m. Shared reservoir pressure 20 bar, both stagnation temperatures 295.15 K, inlet gas mass-flow fraction 0.5 and slip ratio 1. Drag and heat transfer are active; interphase mass transfer and wall friction are zero.

02

The NICFD closure

The number-density interfacial-area law is selected explicitly, with Nᵦ=Nᵈ=10¹¹ m⁻³. The September NICFD source resolves this selector, which is absent from the supplementary YAML. The later polynomial law is a different model and is excluded from this mesh comparison.

03

Eight-state constrained cells

Six phase transport equations and two intrinsic-density EOS equations. Städtke compatibility FVS with the wb nonconservative pairing, MUSCL Van Albada and the 0.05 void filter. Backward Euler, colored AD, square banded Newton, backtracking and coupled algebraic boundary traces.

04

Explicit reference seeding

Each mesh starts independently from the published profile. This checks nearby discrete roots and agreement on the intended branches. It does not demonstrate independent cold-start branch recovery. The prior cold-to-fine attempt selected a supersonic pocket in the nominally subsonic case.

Properties and interpretation

Separate ordinary HEOS bicubic tables, 145 × 200, with explicit populated-stencil admissibility checks. Nitrogen: h=50–400 kJ/kg; water: h=1–140 kJ/kg; both p=0.1–60 bar. The published profiles used JAXProp 0.5.6; the installed version is recorded. No property values are clipped, filled or extrapolated. Mixture Mach uses the acoustic eigenvalues, not Wood’s sound speed. Flow quality differs from static mass quality.

Intentional solver differences from the original publication implementation

The shared solver uses a square banded Newton system and fixed physical scales, coupled trace equations, exact integrated geometry and a local sign-preserving Van Albada formula. The original implementation used normal equations, adaptive column scaling, boundary fixed-point completion and a globally regularized limiter. Later source/pressure-work corrections remain active. These differences and property-version changes can produce finite-mesh differences.

Execution times include JAX compilation and all retained timestep work; they are not repeated warmed performance benchmarks. A model that converges to an unintended regime is not counted as a reproduced case.
