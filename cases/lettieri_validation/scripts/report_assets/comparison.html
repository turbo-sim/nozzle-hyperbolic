Matched closures and numerical interpretation

Both methods use the same smooth-wall Haaland policy: Darcy fD = 64/Re below Re = 2300 and the Haaland turbulent correlation above it, with roughness ε = 0 and the local Dh = 4A/P. Signed wall shear is τw = fDρu|u|/8, with its finite laminar limit 8μu/Dh.

Stationary adiabatic friction changes momentum and entropy while preserving total enthalpy. The no-friction selector removes wall shear in both methods. Reservoir conditions and a choked, supersonic-outlet branch are shared.

The current FVM uses HLL with MUSCL reconstruction and the van Leer limiter, with implicit Euler to converge the steady discrete equations. Each case is sequenced through 50, 100 and 200 cells, starting cold on 50 and prolonging each converged solution to the next grid. CFL and residual normalization reset on each grid. The space marcher uses an independent regular critical state and physical-coordinate integration. Their differences assess numerical verification; agreement with the nonequilibrium experiment is a separate question. Three FVM meshes assess sensitivity; nonmonotonic errors or a plateau do not establish grid independence.
